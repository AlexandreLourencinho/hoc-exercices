# This is the dto package.

## ProductDTOCreate
is sent, as it's name says, by the front / the postman request to create a user

## ProductDTOUpdate
is sent, as it's name says, by the front / the postman request to update a user

## ProductDTOGet
Are the information sent from the back to the front/request.

## ProductDTOStock
is the object sent by the back when querying a stock for a specific product.
